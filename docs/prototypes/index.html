一起AI(17aitech.com)全站 UI 原型。AI 信息 Hub 定位(2026-09-30 升级):连接用户与快速变化的 AI 信息——资讯、教程、开源项目与博主实战文章的聚合平台;深色终端风 + 明暗双主题。 覆盖前台核心 5 屏(M3 已实现 + 二期混合电报流 / 专项 Agent 搜索)、用户中心 3 屏(三期,短信资质解锁后)、admin 后台 14 屏(M5 + 二期电报流治理 / 采集三页 / AI 服务治理三页)。 每页为可独立打开的单文件 HTML(内联 token + 可交互),页面间可点击走通。 需求基准见 requirement/01-requirement.md, 设计 token 真相源见 common.css。

使用说明

  • 直接双击任意 HTML 打开(单文件自包含,零外部依赖;素材仅相对路径 assets/*.jpg)
  • 设计规范:新增/修改任何原型屏前,先读 DESIGN-SPEC.md(设计令牌 / SVG 图标体系 / 组件形态 / QA 门禁 / 红线清单,v1.0 起强制)
  • 主题切换(v0.4.0):每页顶栏 44×24 胶囊双图标滑块(左月右日,点击切换),记忆于 localStorage("proto-theme"),默认暗黑;前台与后台同一风格,明亮模式下代码块/终端窗保持深底(语法色为深底设计)
  • 图标系统(v0.4.0):全站 emoji 已替换为 SVG 矢量图标——每页 顶部内联隐藏 sprite(仅含该页用到的 symbol),正文 <svg class="ic"><use href="#i-xxx"/></svg> 引用;图标源为 antd icons-svg(MIT,与范本项目同源),尺寸约定 .ic 14 / .ic-sm 12 / .ic-lg 18
  • 页面间通过 Header / 侧边栏互链,可点击走通整站流程(登录 → 个人中心 → 后台各页);首页控制台输入框回车可跳 Agent 搜索结果页
  • 状态演示:login 页可切换 pending_binding / 429 频控态;bind-phone 可切成功态;编辑器与令牌页弹窗默认展示关键状态
  • 图表数据为种子伪随机(mulberry32)确定性 mock;所有接口端点标注在各页页脚,与 arch/05-services §5 清单对应
  • 设计 token 真相源:common.css(不被 link,各页内联副本;改 token 先改它再同步)
  • 三期 / 进阶注记:「我的关注」(每用户自定义博主订阅,多租户)为三期规划,仅在电报流与个人中心留置灰入口;长视频切片 + AI 学习笔记为进阶合作功能,前期不实现、不出原型;用户中心 3 屏(登录/绑定/个人中心)待短信签名资质办结后实施(三期,2026-09-30 调整)
  • 待补充:移动端适配页(一期响应式由 Tailwind 自然承载,暂不单独出原型)
