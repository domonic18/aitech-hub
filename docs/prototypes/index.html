使用说明

  • 直接双击任意 HTML 打开(单文件自包含,零外部依赖;素材仅相对路径 assets/*.jpg)
  • 页面间通过 Header / 侧边栏互链,可点击走通整站流程(登录 → 个人中心 → 后台各页)
  • 状态演示:login 页可切换 pending_binding / 429 频控态;bind-phone 可切成功态;编辑器与令牌页弹窗默认展示关键状态
  • 图表数据为种子伪随机(mulberry32)确定性 mock;所有接口端点标注在各页页脚,与 arch/05-services §5 清单对应
  • 设计 token 真相源:common.css(不被 link,各页内联副本;改 token 先改它再同步)
  • 待补充:移动端适配页(一期响应式由 Tailwind 自然承载,暂不单独出原型)
