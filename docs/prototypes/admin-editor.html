智能体军团指挥手册:多 Agent 协作的拆解与编排

AI 实战 · Agents · ≈ 18 min · 草稿预览

为什么要多 Agent

单 agent 长上下文的三大痛点:注意力稀释、工具选择混乱、失败难定位。把任务拆给专职 agent,每个只带自己需要的工具集——

指挥官不写代码,指挥官读地图。

三种编排模式

  • 主从模式:一个 planner 拆任务,N 个 worker 领任务
  • 流水线模式:需求 → 实现 → 评审 → 修复,串行传递
  • 评审环:worker 产出,reviewer 打回,直到通过

代码示例

// planner 派发任务(节选)
const tasks = await planner.split(requirement)
const results = await Promise.allSettled(
  tasks.map(t => workers.dispatch(t))
)
