## 数据口径(全批沉淀的裁定)

- **原币直出不折算**:跨币种、跨计价单位**不可比**——比价/降价判定一律按
  币种×单位分区或记口径变更(`currency_changed`/`unit_changed` 不计入降价)
- **代表价**:token 行=输入价,非 token 行(按张/秒)=生成价(outputPrice);
  排序/区间/比价/散点/降幅% 共用这一把尺
- **两种免费分开**:`is_free`(完全免费,所有价为 0)与 `free_tier`(有免费额度原文);
  前台免费口径为**单选四态**(全部/完全免费/有免费额度/任一免费并集),URL 参数 `free`
  取 all|full|quota|any(旧 `free=1` 按 `full` 承接)
- **未公布 ≠ 便宜**:null 价恒排最后、不进价格区间档、不参与比价与降价判定
- **落库三规则**:行不存在→建 pending;未定稿(`is_pinned=false`)→刷新;人工定稿→不覆盖。
  墓碑:3 天未被刷新 → disabled +「源已下线」注记(仅采集成功且有行时跑)
- **变更史只记采集侧**:后台人工改价不写变更行(口径边界,前台已注明)
- **SEO 红线**:`/pricing/` 列表视图首屏 HTML 必须含**未筛选全量行**(筛掉的行 `hidden`
  藏住);改这块必须用 `next build` + `next start` 验证 SSR(dev 看不出问题)
